* 폴더 생성

* cat .python-version : 버전 확인
* uv python pin 3.12 : 3.12 버전 설치
* uv add fastapi  / uv remve fastapi : fastapi 설치 및 삭제
* uv tree -depth 1 : 1댑스 의 트리를 보여줌
* uv sync : 프로젝트에서 필요한 파이썬 버전과 가상환경을 동기화 한다.
* witch python : 가상환경 확인
* soure .venv/Scripts/activate 가상환경 실행
* python + 파일명 :실행
* uv run + 파일명 : 실행 (학습기간중 이걸로 사용약속)
* vscode : 확작 (python,jupyter) 설치
* uv add ipkernel

## 주피터 노트북 단축키

- A: 위에 쉘 추가
- B: 아래에 쉘 추가
- DD: 해당 쉘 삭제
- M: 마크다운으로 전환
- Y: 코드
- 주석 : # 실행되지 않는 영역 , 소스코드의 설명

## 변수 이름 규칙

- 숫자로 시작 불가 : 1_name (X)
- 공백 불가 : user name (X)
- 하이프(-) 불가: user-age (X)
- 예약어 사용불가: if, def(X)

## 컨벤션

- 스네이크 표기법: user_name, value_list

## 다른 표기법

- 파스칼 케이스 : UserName, ValueList
- 카멜 케이스(단봉낙타법) : userName

- 정수 자료형
    - age = 25
- 실수 자료형
    - pi = 3.14
- 불리언 자료형 (Boolean)
    - is_alive = true
- 배열 Array
    - grade_type = [1,2,3,4]
