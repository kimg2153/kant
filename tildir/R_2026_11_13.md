## 0-2 이번 실승에서 쓰는 명령어

| 명령어 | 역할 |
|---|---|
| docker | pull 이미지:태그	이미지 내려받기 pull: 끌어오다 |
| docker images | 내려받은 이미지 목록 |
| docker run [옵션] 이미지 | 컨테이너 생성 + 실행 |
| docker ps / docker ps -a | 실행 중 / 전체 컨테이너 목록 ps: process status, -a: --all |
| docker exec -it 컨테이너 명령 | 실행 중인 컨테이너에 접속 exec: execute |
| docker logs 컨테이너 | 컨테이너 로그 보기 |
| docker cp 원본 대상 | 내 PC ↔ 컨테이너 파일 복사 cp: copy |
| docker stop / docker start | 컨테이너 정지 / 재시작 |
| docker rm / docker rmi | 컨테이너 삭제 / 이미지 삭제 rm: remove, rmi: remove image |

## 0-3. 이번 실습에서 쓰는 docker run 옵션 (이것만 기억하면 됩니다)

| 옵션 | 의미 | 예시 |
|---|---|---|
| `-it`<div><small>-i: --interactive</small></div><div><small>-t: --tty</small></div> | 터미널을 붙여 대화형으로 실행<div><small>-i: 키보드 입력(STDIN)을 열어 둠</small></div><div><small>-t: 가상 터미널(TTY, TeleTypewriter)을 할당해 프롬프트가 보이게 함</small></div> | `-it ubuntu bash` |
| `-d`<div><small>--detach</small></div> | 백그라운드 실행<div><small>터미널에서 떼어내(detach) 실행</small></div> | `-d nginx` |
| `--name` | 컨테이너 이름 지정 | `--name my-nginx` |
| `-p 호스트:컨테이너`<div><small>--publish</small></div> | 포트 연결<div><small>컨테이너 포트를 외부에 공개(publish)</small></div> | `-p 8080:80` |
| `-e 키=값`<div><small>--env</small></div> | 환경 변수 전달<div><small>environment variable</small></div> | `-e MYSQL_ROOT_PASSWORD=1234` |
| `-v 볼륨:경로`<div><small>--volume</small></div> | 볼륨 연결(데이터 보존) | `-v pgdata:/var/lib/postgresql` |

>📌 한 글자 옵션은 -i -t → -it처럼 붙여 쓸 수 있습니다. 풀네임은 --interactive --tty처럼 하이픈 두 개(--)로 씁니다.

>📌 이미지 vs 컨테이너: 이미지는 "설치 파일(틀)", 컨테이너는 그 틀로 찍어낸 "실행 중인 프로그램"입니다. 이미지 하나로 컨테이너를 여러 개 만들 수 있습니다.
