# GIT

1.  GIT 환경설정  
* git init : 깃 초기화 (루트에서 하지말고 폴더 생성해서) 새 저장소 만들기
* git config --global user.name "Kimjun"
* git config --global user.email "kimg2153@gmail.com"
    - git config에 이름과 이메일 추가
* git remote add origin 주소
    - git과 github 의 주소를 입력해 원격 저장소 연결


2.  Git 명령어
* git status : 현재 상태 확인
* git add 파일명 : 해당 파일 Staging에 올리기 
* git add . : 수정한 모든 파일을 Staging에 올리기
* git log : 이력보기
* git log --oneline : 한줄씩 출력
* git log --oneline --all : 헤드 위치에 상관없이 전체 확인
* git commit -m  "상태 : 내용 "
    - feat : 새 기능추가
    - fix : 버그 수정
    - docs : 문서 수정
    - test : 테스트 코드 추가
    - refact : 코드 리펙토링 등등
* git switch : 브랜치 이동
* git branch : 브랜치 목록·생성·삭제
* git checkout : 이동·복원
* git push origin(위에 설정한 주소) main(브랜치명) 

3. 개념
* Working Direcory : 작업폴더 , 실제로 파일을 편집하는곳
* Staging Area : Index 다음 커밋에 담을 변경을 골다 두는 영역. <br> .git/index 파일로 관리되는 논리적 영역
* Repository : 커밋(스냅숏) 이력이 저장되는 영역
