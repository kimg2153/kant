## 서브쿼리 기초 

- 괄호 안의 SELECT를 먼저 실행해 그 결과를 바깥 쿼리의 조건으로 씁니다. 결과가 값 하나면 =,> 로 비교하고, 여러개이면 IN이나 EXIST를 씁니다.

> 오늘의 목표 <br> 값 하나를 돌려주는 서브 쿼리로 바깥 쿼리의 조건을 만든다.<br> IN·NOT IN과 서브쿼리를 쓰고, NOT IN에 NULL이 섞이면 0행이 되는 이유를 설명한다. <br> EXISTS·NOT EXISTS로 "관련 행이 있는지/없는지"를 묻는다.

``` sql
SELECT course_id, fee
FROM courses
WHERE fee > (
    SELECT AVG(fee) FROM courses
);
```

### 서브쿼리만 먼저 실행해 보기
- "평균보다 비싼 강좌"를 구하려면 평균부터 알아야 합니다. 안쪽에 들어갈 쿼리를 따로 실행해 봅니다.

> SELECT AVG(fee) FROM courses;

### 평균보다 비싼 강좌
- 숫자 81785.71을 옮겨 적는 대신, 위 쿼리를 괄호로 감싸 그대로 넣습니다.
```sql
SELECT course_name, fee
FROM courses
WHERE fee > (SELECT AVG(fee) FROM courses)
ORDER BY fee DESC, course_name;
```

###  실행 계획으로 순서 확인
- EXPLAIN을 앞에 붙이면 쿼리를 실행하지 않고, 데이터베이스가 어떤 순서로 처리할지(실행 계획)를 보여 줍니다. (COSTS OFF)는 예상 비용 숫자를 빼고 보는 옵션입니다.
```sql
EXPLAIN (COSTS OFF)
SELECT course_name, fee
FROM courses
WHERE fee > (SELECT AVG(fee) FROM courses);
```

### 실험: 여러 행을 =로 비교하면
- 송유나 회원이 들은 강좌를 = 로 찾아봅니다.
``` sql
SELECT course_name
FROM courses
WHERE course_id = (SELECT course_id FROM enrollments WHERE member_id = 38);
```

### IN과 NOT IN

``` sql
SELECT course_name
FROM courses
WHERE course_id IN (SELECT course_id FROM enrollments WHERE member_id = 38);
```
- 서브쿼리 결과에 같은 번호가 여러 번 있어도 IN은 "목록에 있는가"만 보므로 강좌는 한 번씩 나옵니다. 같은 질문을 JOIN으로 풀면 기록 수만큼 6행이 나옵니다.

- 수강 기록이 한 번도 없는 회원입니다. 가입만 하고 강좌를 듣지 않은 회원에게 안내 문자를 보낼 때 씁니다.

``` sql
SELECT member_id, name, join_date
FROM members
WHERE member_id NOT IN (SELECT member_id FROM enrollments)
ORDER BY member_id;
```
### 실험: NOT IN에 NULL이 섞이면
- 맡은 강좌가 없는 강사를 같은 방법으로 찾아봅니다. 2장에서 차예린 강사가 강좌를 맡지 않았다는 것을 확인했습니다.

``` sql
SELECT name
FROM instructors
WHERE instructor_id NOT IN (SELECT instructor_id FROM courses);
```

- 서브쿼리 결과에 자유이용 강좌의 NULL이 섞여 있기 때문입니다. 8 NOT IN (1, 3, NULL, …)은 "8 <> NULL"을 판단할 수 없어(UNKNOWN) 참이 되지 못합니다. 서브쿼리에서 NULL을 빼면 답이 나옵니다.


### EXISTS와 NOT EXISTS

- EXISTS는 서브쿼리가 한 행이라도 돌려주면 참입니다. 서브쿼리 안에서 바깥 테이블의 열(i.instructor_id)을 쓰므로, 바깥 행마다 서브쿼리가 다시 실행됩니다. 이런 서브쿼리를 상관 서브쿼리라고 합니다.


``` sql
SELECT i.name
FROM instructors i
WHERE NOT EXISTS (SELECT 1
                  FROM courses c
                  WHERE c.instructor_id = i.instructor_id);
```
- 사물함을 배정받았지만 이번 달(2026-11) 수강 신청을 하지 않은 회원입니다. 사물함 회수 안내 대상입니다.

``` sql
SELECT l.locker_no, l.member_id
FROM lockers l
WHERE NOT EXISTS (SELECT 1
                  FROM enrollments e
                  WHERE e.member_id = l.member_id
                    AND e.enroll_month = '2026-11')
ORDER BY l.locker_no;

``` 

- 반대로 EXISTS는 "한 번이라도 취소한 적이 있는 강좌"처럼 관련 기록이 있는 행만 남깁니다.

``` sql
SELECT c.course_id, c.course_name
FROM courses c
WHERE EXISTS (SELECT 1
              FROM enrollments e
              WHERE e.course_id = c.course_id
                AND e.status = '취소')
ORDER BY c.course_id;
```
