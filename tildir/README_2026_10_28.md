# Git 

1. .git 폴더
* git init 으로 깃 초기화를 하면 해당 폴더에 main 이라 나오며 .git 폴더가 생성된다.
    * git을 삭제하고 싶으면 .git 폴더만 rm -rf .git 으로 삭제
2. git에서 관리 제외 항목 ignore
* touch .gitignore 파일을 생성 내부에 제외할 항목들을 작성
    * ex: *.dat , *.tmp , [Ll]og(폴더) 등
3. clone
* git clone + 주소  
    * 홈(root)또는 원하는 위치에서 git clone + 깃허브 주소를 입력해서 해당위치에 생성되도록 한다.
    * git commit -m "feat: 내용  (WIP)" 현재 진행중이라는 메시지 포함
 4. reset  : 커밋을 지우는 것이 아니라 브렌치가 가리키는 위치를 옮기는 것. 빠진 커밋은 한동안 git reflog 로 찾아 복구할 수 있다.

 * soft : 작업폴더, staging 유지 , repository 초기화
 * mixed : 작업폴더 유지 , staging , repository 초기화
 * hard : 작업폴더 , staging, repository 초기화 , hard 는 커밋하지 않은 작업을 영구히 잃을 수 있는 위험한 명령이다.
    * git reflog : 지금까지 사용했던 로그 내용들
    * git reset --soft,mixed,hart  HEAD@{6} (reflog의 HEAD@ 을 찾아서 입력)
